# Captures d'écran

Placez ici les captures d'écran de l'application :

- `home.png` — page d'accueil
- `quiz.png` — quiz en cours (une question avec ses choix)
- `score.png` — score final

Pour les générer :

1. Lancez l'application (`docker compose up --build` ou le mode développement).
2. Naviguez sur les pages correspondantes et faites une capture d'écran.
3. Enregistrez les fichiers PNG dans ce dossier avec les noms ci-dessus.

Le `README.md` à la racine référence ces images.
